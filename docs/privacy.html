Política de Privacidade

Última atualização: 23 de setembro de 2026

1. Dados utilizados

Quando o comando /start é utilizado, o aplicativo pode registrar o identificador do usuário do Discord e, quando aplicável, o identificador do servidor, para contabilização única nas estatísticas do serviço.

2. Finalidade

Os dados registrados são utilizados para funcionamento, manutenção, segurança e estatísticas do Gols Flamengo. O aplicativo não exige nome real, endereço, telefone ou dados de pagamento para utilizar seus comandos.

3. Compartilhamento

O Gols Flamengo não vende os identificadores registrados. O funcionamento depende de provedores de infraestrutura e do próprio Discord, que podem processar informações conforme suas próprias políticas.

4. Retenção e segurança

Os dados necessários às estatísticas podem ser mantidos enquanto o serviço estiver em operação. Medidas técnicas razoáveis são utilizadas para proteger a infraestrutura e limitar o acesso aos dados.

5. Alterações

Esta política pode ser atualizada quando houver mudanças no funcionamento do aplicativo ou no tratamento de dados.

Gols Flamengo — aplicativo independente para consulta e reprodução de um acervo de gols no Discord.
